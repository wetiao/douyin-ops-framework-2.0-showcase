# 本地预览

这是“抖音运营框架 2.0”商业展示页的本地静态预览，不连接正式后台，不读取账号、Cookie、密钥或运行数据。

## 打开方式

直接双击：

```text
preview/index.html
```

或在本目录执行：

```powershell
Start-Process .\index.html
```

页面使用相对路径引用 `../assets/`，无需启动服务器，也不需要安装依赖。

## 内容范围

- 首屏：产品名称、定位、核心卖点、年度参考价、咨询入口；
- 系统组成：AI Skill、SDK、业务接口、插件运行时、验证工具与工作台的关系；
- 定制示例：业务需求 → 定制规则 → 插件输出；
- 业务场景：线索、AI 沟通、竞品/热点、直播游戏、数据报告、页面；
- 客户与购买价值、年度报价、交付边界；
- 截图位、录屏位与联系入口；
- FAQ 与事实口径。

## 交互与兼容

- 响应式布局，桌面、平板和手机宽度均可阅读；
- 移动端顶部菜单可展开/收起；
- 图片可点击查看大图；
- FAQ 使用原生 `<details>`，无依赖；
- 支持键盘导航、`prefers-reduced-motion` 和跳到主要内容；
- 页面不依赖 CDN、外部字体或第三方脚本。

## 当前验证

已在本地静态环境检查：

- 桌面：1440 × 960 首屏与 1440px 长页分段检查；
- 手机：390 × 844 真实宽度布局（通过 390px iframe 视口检查）；
- 全部主要区块、图片、锚点、FAQ 与联系入口可见；
- 移动端导航可以展开/收起，图片链接可打开大图；
- 无自动外部资源请求，图片路径有效。

未做真实用户测试、Safari/Firefox 全量兼容测试或正式业务验收。
